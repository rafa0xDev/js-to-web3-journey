## Daily structure

Each session runs ~90 minutes, 6 days a week:

1. **Learn (15 min)** — one concept, not two
2. **Predict, then run (30 min)** — guess the output before executing any code
3. **Build (35 min)** — something small that only works if the concept is understood
4. **Log (10 min)** — write a short reflection in English, then commit
